# 仪表盘

## 当前状态与范围

仪表盘通过[页面](../admin/geminus/Admin/Views/dashboard.php)展示当前用户可见的模块内容。共享契约与聚合服务位于 `Geminus\Admin\Libraries\Dashboard`，统一展示由 `DashboardCell` 完成，公告模块已接入。

仪表盘是当前用户的工作首页，由后台底座统一展示各模块提供的指标、待办及快捷入口。它不是独立报表系统，也不在 Admin 中写死公告等业务模块的统计逻辑。

第一版采用服务端渲染，随页面刷新更新；不提供拖拽布局、用户自定义面板、在线组件配置、实时推送、图表引擎或任意 HTML 插槽。不增加仪表盘专用数据表或单独的业务权限目录。

## 业务需求

- 用户只看到自己有权读取的数据及有权使用的入口；同一模块可以按用户权限提供不同内容。
- 指标说明统计口径，并可进入对应列表；待办只显示少量记录，通过“查看全部”进入模块页面。
- 没有可见内容时显示正常空态，不展示无权限模块的名称、数量或错误状态。
- 单个模块的数据准备失败不阻断其他模块；不可用与没有记录、数量为零是不同状态。
- 公告作为首个业务接入示例，验证模块注册、不同角色的数据隔离及统一展示。

## 职责划分

| 所属层 | 职责 |
| --- | --- |
| 模块 Registrar | 声明提供者标识、服务名、模块名称、初筛权限及排序，不查询数据或实例化服务 |
| 模块 Services | 显式装配提供者及其 Model 等依赖，默认创建非共享实例 |
| 模块提供者 | 接收当前用户，检查业务授权，准备该用户可见的展示项，不读取全局请求或生成 HTML |
| 模块 Model | 执行统计及有界列表查询，落实资源可见性条件 |
| Admin Services | 按注册配置装配提供者及聚合服务，验证注册契约，不承载业务查询 |
| Admin 聚合服务 | 初筛权限，调用提供者，校验展示项，隔离模块异常并形成统一结果 |
| Dashboard Controller | 获取当前用户与语言上下文，调用聚合服务，映射为页面参数 |
| Admin Cell / View | 本地化与格式化展示、输出转义、统一布局及空态，不查询业务数据或决定授权 |

共享契约及聚合能力归入 `Geminus\Admin`，模块实现归入自己的 `Libraries`，查询留在所属 Model。沿用[通用界面组件](ui-components.md)和[业务模块约定](example-business-module.md)，不创建万能查询器或配置驱动的整页 CRUD。

## 模块注册与调用

### 注册配置

`Geminus\Admin\Config\Dashboard` 通过模块的 `Registrar::Dashboard()` 合并 `providers`。形式沿用现有[菜单及上传来源注册](../admin/modules/Announcements/Config/Registrar.php)。配置在 CI4 Registrar 发现完成后逐项核对贡献的标识，防止默认数组合并静默覆盖重复注册。

`providers` 以稳定的模块标识为键，每项包含：

| 字段 | 契约 |
| --- | --- |
| 标识键 | 小写字母、数字和连字符组成，最长 64 字符，全局唯一，例如 `announcements` |
| `service` | 提供者服务名，统一使用小写；由 Services 显式装配 |
| `label` | 模块语言文件中的名称键，用于模块标题及不可用状态 |
| `permissions` | 具体两段式权限名称列表，满足任一权限才调用提供者；空列表表示所有已登录用户可进入初筛 |
| `order` | 整数，越小越靠前；相同值按提供者标识排序 |

公告模块的注册配置：

```php
public static function Dashboard(): array
{
    return ['providers' => [
        'announcements' => [
            'service' => 'announcementdashboardprovider',
            'label' => 'Announcements.title',
            'permissions' => ['announcements.access', 'announcements.manage'],
            'order' => 100,
        ],
    ]];
}
```

重复标识、无效服务名或不符合接口的实例属于配置错误，会抛出明确异常，不能静默覆盖或伪装成业务空态。

### 提供者接口

`Geminus\Admin\Libraries\Dashboard\DashboardProvider` 接口提供 `items(User $viewer): array`，返回展示项列表。`User` 使用项目认证用户实体兼容的 Shield 类型；提供者通过构造函数接收持续使用的协作对象。

每个通过初筛的提供者每次请求调用一次；返回空列表表示当前用户没有可展示内容。聚合服务不在各展示组件中重复调用提供者，也不默认共享用户相关数据或启用 Cell 缓存。

初筛权限不等于数据授权。提供者必须再次按实际展示项及资源检查权限，例如公告阅读权限不能用于获取草稿数量。管理员身份也不替代模块的业务授权规则。

## 展示项契约

第一版只支持 `metric`、`list` 和 `shortcut`，不接受模板路径、Cell 类名、脚本、回调或任意 HTML。展示项只使用明确字段，不把数据库整行记录直接传给页面。

### 公共字段

| 字段 | 契约 |
| --- | --- |
| `id` | 提供者内唯一的稳定标识，格式与提供者标识相同；全局键由提供者标识及此 ID 组成 |
| `type` | `metric`、`list` 或 `shortcut` |
| `title` | 本地化语言键，不使用用户输入作为语言键 |
| `order` | 整数；同模块内按此值及 ID 稳定排序 |

标题及固定说明由展示层按当前语言翻译；业务记录标题作为纯文本展示。数量按当前语言格式化，时间以 UTC 的 ISO 8601 字符串传递，再按当前用户时区显示。三种语言均需提供固定文案。

### 指标 `metric`

- `value`：非负整数，第一版只支持计数，不接受预先格式化的 HTML 或任意状态字符串。
- `description`：必填语言键，说明统计范围，例如“当前可管理的草稿”。
- `link`：可选，指向同一统计口径的模块列表；没有对应页面时不强行提供链接。

### 列表 `list`

- `rows`：最多 5 条，每条包含纯文本 `title`、受控 `link`，以及可选的 UTC `time`；由模块执行有界查询及稳定排序。
- `emptyLabel`：必填语言键，在有权访问但没有记录时展示。
- `moreLink`：可选，指向模块完整列表，并包含本地化操作名称。
- 用于待办或最近记录，不在仪表盘内分页，也不执行写操作；展示项标题须明确是哪一种列表。

### 快捷入口 `shortcut`

- `link`：必填，进入用户有权访问的模块页面，例如新建表单。
- `icon`：可选，使用开发者指定的项目 Tabler 图标名，不接受 HTML 标记。
- 只提供 GET 导航，不在首页直接发布、删除、审批或触发其他写操作。

### 受控链接

`link` 与 `moreLink` 使用相同结构：`route` 为有效的后台命名 GET 路由（别名以 `admin/` 开头，路径位于 `{locale}/admin` 下），`arguments` 为匹配路由的整数或字符串参数列表，`query` 为模块明确构造的标量筛选参数；`moreLink` 另带操作名称语言键 `label`。不接受外部 URL，不直接传入整个请求参数。

链接按项目现有方式补齐当前 locale；参数和查询由路由及 URL API 编码，不拼接未转义字符串。无效路由或不匹配参数视为展示项契约错误，不生成损坏链接。目标页面独立检查认证、权限、资源存在性及可见性，仪表盘入口不授予额外权限。

## 展示与异常处理

模块按注册排序展示为无额外卡片外壳的独立区域，模块内指标、列表及快捷入口使用固定的 Tabler 展示方式。桌面允许多列，移动端单列；同类组件保持稳定尺寸，长标题换行，不让数量、文本及按钮重叠。

聚合服务先对提供者执行权限初筛，再获取并校验完整返回结果；某提供者异常或返回非法展示项时，整个模块区域显示统一的本地化“暂不可用”，保留其他模块结果，不显示部分统计或错误详情。日志记录提供者标识及服务端异常诊断，不向页面暴露 SQL、堆栈或凭据。

没有通过初筛的模块不调用、不显示错误占位。正常返回空列表的模块不显示区域；所有模块均无内容时显示全页空态。有展示项的空列表保留该列表的空态，有效指标为零时正常显示 `0`。

第一版不提供异步加载状态、手动重试按钮或共享缓存。若后续引入缓存，必须明确用户、授权及语言隔离和失效策略，不能复用其他用户的统计结果。

## 公告接入示例

公告模块通过 `AnnouncementDashboardProvider` 提供内容，由模块 Services 装配独立的 `AnnouncementModel`。管理者的最近记录按创建时间及 ID 倒序；只读者按发布时间及 ID 倒序。两种列表均由数据库查询限制为 5 条。

| 用户能力 | 展示内容 |
| --- | --- |
| `announcements.manage` | 草稿数量，链接到草稿筛选列表；新建公告入口；最近 5 条可管理公告，链接到详情及完整列表 |
| 仅 `announcements.access` | 最近 5 条已发布公告，按发布时间及 ID 倒序；链接到详情及公告列表 |
| 无公告权限 | 不调用公告提供者，不展示公告区域 |

同时具备阅读和管理权限时只展示管理者版本，不重复生成列表。草稿统计不能因阅读权限、请求筛选参数或其他模块的注册内容而泄露。公告示例不额外引入审批或定时发布功能。

## 验收要求

- 注册两个独立提供者即可扩展首页，不修改 Dashboard Controller 或 Admin 视图中的业务分支；支持未注册任何提供者。
- 验证配置冲突及无效实例可诊断，模块与展示项排序稳定，每个可见提供者每请求只调用一次。
- 公告测试覆盖管理者、只读者、无权限用户，以及撤销授权后的再次访问；草稿标题、数量及入口均不得泄露。
- 验证链接 locale、参数及筛选口径，目标接口继续独立拒绝无权限或不可见资源访问。
- 覆盖零计数、空记录、无可见模块、单模块异常及非法展示项；模块失败不使首页失败，也不显示为零。
- 验证业务标题转义、链接编码、三种语言及用户时区；列表最多 5 条，不以读取全量记录后截断实现。
- 浏览器检查桌面与移动端布局、长标题、键盘可访问入口及空态；首页不依赖 JavaScript 才能读取基本内容。
- 相关行为测试位于 `admin/tests/unit/DashboardTest.php` 和 `admin/tests/unit/AnnouncementsTest.php`；实现变更需运行相关测试、PHP 格式检查及按风险分级的独立审查。
